# go-opik

Unofficial Go client for the Opik REST API, generated from the OpenAPI document Opik publishes. If you only want to use the client from an agent, read [.agents/skills/go-opik/SKILL.md](.agents/skills/go-opik/SKILL.md) instead; this file is about changing the code.

## Architecture

One generated package, `opik`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://raw.githubusercontent.com/comet-ml/opik/main/sdks/code_generation/fern/openapi/openapi.yaml` to `api/openapi.yaml` → `scripts/patch-spec.sh` invokes the Go YAML patch tool in `internal/cmd/patch-spec` and writes `api/openapi.fixed.yaml`, retagging bare `=` enum values as strings and normalizing description punctuation → oapi-codegen with `config.yaml` → `client_*.gen.go` through `scripts/split-gen.sh`.

## Stack

- Go 1.26.9.
- oapi-codegen, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client_*.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, YAML normalization, generated file splitting, lint and security scans.
- `internal/cmd/patch-spec/`: the Go YAML patch tool.
- `api/`: the downloaded spec, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- Bare `=` YAML enum values acquire the YAML value tag. Retag them as strings before a strict parser reads the spec.
- Without the `number` to `float64` mapping in `config.yaml`, unformatted numbers become `float32`.
- Cloud authentication is a bare API key in `Authorization`, with no `Bearer ` prefix, plus `Comet-Workspace`. The spec describes these headers but declares no security scheme that installs them automatically.
- Base URLs include `/api`; main resource paths start with `/v1/private/` and OAuth paths use `/oauth/`. The cloud base URL is `https://www.comet.com/opik/api`.
- Method names come from upstream operation IDs. The spec includes UI and internal operations as well as SDK endpoints. Generate all operations.
- The upstream introduction describes the API as beta. `make generate` downloads the current spec, so an upstream update can change generated code. Review the generated diff.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
